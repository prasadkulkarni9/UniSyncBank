# UniSyncBank
In today’s age , managing multiple bank accounts, tracking transactions, and transferring funds can be tedious. Most existing solutions either lack real-time transaction updates or require third-party tools for fund transfers, creating fragmented experiences for users.
Unisync aims to overcome these challenges by offering a single platform that integrates multiple bank accounts and delivers real-time transaction updates while enabling secure peer-to-peer transfers.
Unisync provides Server Side Authentication and a better user experience.

Many banking apps have complicated user interfaces that makes navigation difficult. They provide basic financial details but lack deeper insights. They face problems working on different devices.

Unisync seeks to provide users with a unified platform for managing their finances across multiple bank accounts, receiving real-time transaction updates, and making peer-to-peer transfers without needing external services. 

UniSync uses ShadCN utility to combine features of Tailwind CSS,  Radix UI and React libraries like ChartJS components to provide attractive user interface and a better user experience.
It uses React libraries  like React Hook Forms , TypeScript and Zod with NEXTJS Framework for better form validation  with less re-rendering.
For Server Side Rendering/Authentication it uses Appwrite and for linking application with bank accounts it uses Plaid.
For real-time transactions , it uses  Dwolla API and to monitor the performance and debug it ,we use Sentry.
